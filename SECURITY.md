# Security Policy

## Supported versions

Security fixes are currently provided for the latest version on the `main` branch.

| Version        | Supported |
| -------------- | --------- |
| main           | Yes       |
| Older versions | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, contact:

security@allydevs.com

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- Any suggested mitigation, if available

We will review the report and respond as soon as reasonably possible.

Please allow us time to investigate and address the issue before publicly disclosing it.
